# Ceph: سیستم ذخیره‌سازی توزیع‌شده

## 📌 معرفی
یک سیستم ذخیره‌سازی توزیع‌شده و مقیاس‌پذیر است که می‌تواند به‌عنوان **Block Storage، File Storage و Object Storage** عمل کند. این سیستم برای تأمین ذخیره‌سازی **قابل اعتماد، خودترمیم‌شونده و بدون نقطه شکست مرکزی** طراحی شده است.

---

## ⚡ ویژگی‌های کلیدی
- **📦 پشتیبانی از سه نوع ذخیره‌سازی**:
  - **Block Storage (RBD):** مانند Amazon EBS، مناسب برای ماشین‌های مجازی و دیتابیس‌ها.
  - **File Storage (CephFS):** مانند NFS، برای به‌اشتراک‌گذاری فایل‌ها.
  - **Object Storage (RGW):** مانند Amazon S3، برای ذخیره‌سازی داده‌های غیرساختاریافته.
- **🔗 توزیع‌شده و بدون SPOF (Single Point of Failure)**
- **🛠 خودترمیم‌شونده (Self-healing)**
- **📊 مقیاس‌پذیری بالا بدون محدودیت مرکزی**

---

## ⚙️ نحوه کارکرد
Ceph از **الگوریتم CRUSH** برای توزیع داده‌ها در چندین هارد و سرور استفاده می‌کند.  
داده‌ها در قالب **OSD (Object Storage Daemons)** ذخیره شده و به‌طور خودکار کپی و بازتوزیع می‌شوند.

### 🏗 اجزای اصلی:
- **Monitor (MON):** مدیریت وضعیت کلاستر و متادیتا.
- **Object Storage Daemon (OSD):** مدیریت داده‌ها روی هارددیسک.
- **Metadata Server (MDS):** مدیریت فایل‌ها در CephFS.
- **RADOS Gateway (RGW):** ارائه API سازگار با S3 برای Object Storage.

## 🏁 نتیجه‌گیری
Ceph یک **راه‌حل همه‌کاره و مقیاس‌پذیر** برای ذخیره‌سازی در مقیاس بالا است و برای **دیتاسنترها، کلودهای خصوصی و سازمان‌های بزرگ** گزینه‌ای ایده‌آل محسوب می‌شود.
