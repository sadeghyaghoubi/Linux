# Cluster Map
هسته مرکزی سیستم Ceph است که وضعیت کلی Cluster را توصیف می‌کند. این نقشه به صورت دینامیک به‌روز می‌شود و توسط MONها (Monitors) مدیریت می‌گردد.

## اجزای اصلی Cluster Map

### 1. OSD Map
**وظیفه اصلی**:  
ردیابی وضعیت تمام OSDها (Object Storage Daemons) در خوشه

**اطلاعات کلیدی**:
- لیست تمام OSDها
- وضعیت هر OSD (up/down)
- وزن (weight) هر OSD
- PG (Placement Group) mapping

### 2. Monitor Map
**وظیفه اصلی**:  
نگهداری اطلاعات مربوط به مانیتورها

**اطلاعات کلیدی**:
- آدرس و پورت MONها
- نسخه پروتکل
- تاریخچه تغییرات

### 3. PG Map
**وظیفه اصلی**:  
ردیابی وضعیت Placement Groupها

**اطلاعات کلیدی**:
- آمار PGها
- وضعیت replication
- آمار استفاده از فضای ذخیره‌سازی

### 4. CRUSH Map
**وظیفه اصلی**:  
توصیف توپولوژی فیزیکی خوشه

**اطلاعات کلیدی**:
- سلسله مراتب دستگاه‌ها (host/rack/row/datacenter)
- قوانین توزیع داده (CRUSH rules)
- وزن دستگاه‌ها

### 5. MDS Map
**وظیفه اصلی**:  
ردیابی وضعیت Metadata Serverها برای CephFS

**اطلاعات کلیدی**:
- وضعیت MDSها
- متادیتای فایل سیستم
- جدول اینودها

## نحوه عملکرد
1. **به‌روزرسانی**: هر تغییر در خوشه باعث به‌روزرسانی Cluster Map می‌شود
2. **توزیع**: MONها تغییرات را به تمام گره‌های خوشه منتشر می‌کنند
3. **هماهنگی**: تمام کامپوننت‌های Ceph از نسخه یکسان Map استفاده می‌کنند
